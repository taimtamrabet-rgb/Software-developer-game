# Dev Career

A career/life simulation game. Graduate with a CS degree, climb the ladder as a
software developer or game developer — from small studios up to AAA/Big Tech —
found and grow your own studio, buy houses and cars, and age month by month.

Built with React, TypeScript, Vite, Tailwind CSS, and Zustand (with
localStorage save persistence). Responsive UI: bottom tab bar on mobile,
sidebar navigation on desktop.

## Running locally

```bash
npm install
npm run dev
```

## Gameplay overview

- **Career**: pick software or game development, apply to procedurally
  generated job offers, get promoted over time (Junior → Mid → Senior → Lead →
  Principal), and climb company tiers (Startup/Indie → Growth-stage/Small →
  Mid-size/AA → Big Tech/AAA → Elite/Legendary).
- **Skills**: take courses to raise Coding, Design, Business, and Marketing
  skills, which unlock higher-tier jobs.
- **Studio**: once you have enough savings and experience, found your own
  software, tech, or game studio. Hire employees, grow it from a garage to a
  global HQ, and sell it for a lump sum whenever you want to cash out.
- **Life**: buy houses (from a rented apartment to a beachfront villa) and
  cars (from a used hatchback to a supercar) that boost happiness but cost
  money to maintain.
- **Time**: every "Next Month" click ages your character, pays salaries or
  studio profit, deducts living expenses, and may trigger random life events.
- **Retirement**: retire any time (or automatically at 75) to see a final
  summary of your career.

Progress is saved automatically to your browser's localStorage.
